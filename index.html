        📲 Deploy to GitHub from iPhone

        Option 1 — Unzip in Files, upload in Safari
        1. Files app → tap the .zip once to extract it.
        2. github.com → New repository → Add file → Upload files.
        3. Tap Choose your files → Browse → select everything inside the extracted folder (for sub-folders, repeat per folder, or use Option 2).
        4. Commit, then Settings → Pages → Branch main / root → Save.
        Option 2 — Direct pusher (GitHub Contents API)

        Creates a fine-grained token at github.com/settings/tokens with Contents: Read and write on your repo only. The token stays in this browser tab and is sent only to api.github.com.
